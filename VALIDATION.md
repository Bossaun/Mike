# Проверка новой реализации — 14 октября 2026

- Python 3.12.14, Linux x86_64. Установка зависимостей и editable package успешна.
- 56 тестов pytest пройдены, нулевых/пропущенных тестов нет.
- Полный цикл проверен через Telegram handlers, SQLite, outbox, Sheets projection;
  внешние API и ответы модели искусственные. Есть проверка повторной встречи,
  обычного ответа на сообщение бота, завершения, сводки и открытия базы после рестарта.
- Проверены отсутствие сроков/ответственных, предложения, неоднозначные ответы,
  «почти готово», недоступная чужая задача, бюджет и оба модельных адаптера.
- Проверены строки задач за 149 и записи отчётов/касаний в строке 201;
  отказ первому руководителю не препятствует второму.
- Проверены can_reply/24 часа/fallback, ошибки, 429, unknown delivery,
  edits/deletions, отмена необработанного удалённого события, защита от own messages.
- Docker image собран из актуального кода. Из-за отсутствия DNS внутри build
  wheels скачаны с PyPI с TLS-проверкой; использован PIP_NO_INDEX=1.
- CLI ingest дважды выполнен внутри контейнера от UID 10001: одна задача,
  одно событие, одно сообщение pending. Никакая внешняя отправка не выполнялась.
- Compose конфигурация проверена командой config --no-env-resolution --no-interpolate.
- Официальная документация Telegram прочитана после первоначального HTTP 403.

Не проверены: прежний пакет на MacBook и его 63 теста, реальная модель и качество
разбора, Business connection в Telegram, живые сообщения, состав вашей Google-таблицы,
service-account auth, реальные Sheets edits, Railway и постоянно работающий сервер.
Отсутствуют ключи и проверенные Telegram/табличные идентификаторы. Приложение не развёрнуто.

В черновике облачной среды сохранены install_script, start_skill, необходимые домены,
требования TELEGRAM_BOT_TOKEN и MODEL_API_KEY (без значений).
Сохранение черновика не означает публикацию или применение секретов.
Исходники созданы в /workspace/Mike; GitHub push не выполнялся.
